# Signup Project

A full stack signup form built with MERN stack.

## Tech Stack
- React (Frontend)
- Node.js + Express (Backend)
- MongoDB + Mongoose (Database)

## Features
- User registration form
- Duplicate email check
- Form validation
- REST API with Express

## How to Run

### Backend
cd backend
npm install
nodemon server.js

### Frontend
cd frontend
npm install
npm start
